# BÀI TẬP LỚN PHÂN TÍCH DỮ LIỆU GIÁ VÀNG & TỶ GIÁ

## 1. Cấu trúc thư mục

- `data/`: Chứa dữ liệu CSV đã xử lý.
- `logic_phantich.py`: Mã nguồn chứa Lớp (Class) xử lý logic, tiền xử lý dữ liệu và vẽ biểu đồ.
- `app.py`: Mã nguồn Dashboard tương tác bằng Streamlit.
- `Main_Notebook.ipynb`: Jupyter Notebook phân tích chi tiết từ A-Z.
- `requirements.txt`: Danh sách các thư viện Python cần thiết.

## 2. Hướng dẫn cài đặt & Chạy chương trình

1. Cài đặt các thư viện phụ thuộc:
   ```bash
   pip install -r requirements.txt
   ```
